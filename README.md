# Cloudflare DoH Switcher (Windows 11)

Простая легковесная утилита для быстрого включения и отключения шифрованного DNS (DNS-over-HTTPS) от Cloudflare на Windows 11.

## Возможности

- **Включение Cloudflare DoH в один клик:**
  - Настройка IPv4 DNS-серверов: `1.1.1.1` и `1.0.0.1`.
  - Включение шаблона DoH (`https://cloudflare-dns.com/dns-query`) в системном реестре Windows 11 (`Dnscache\InterfaceSpecificParameters`).
- **Отключение / возврат к настройкам по умолчанию:**
  - При повторном запуске сбрасывает DNS активных сетевых адаптеров на автоматическое получение по DHCP.
  - Очищает DoH-параметры из реестра.
- **Встроенный UAC-манифест:** автоматический запрос прав администратора при запуске.

## Требования

- Windows 11 (сборка 22000 или выше)
- Права администратора

## Сборка

Проект разработан на .NET 8 (C#) и собирается в виде single-file исполняемого файла:

```powershell
dotnet build -c Release
```

Готовый бинарник будет расположен в `bin/Release/net8.0-windows/win-x64/publish/` (или `Release/`).
